04   Grammar Patterns

Key grammar structures used in the video. Each pattern includes real examples.

〜についてお話ししたいと思います
「〜について」는 '~에 대해', 「お話ししたいと思います」는 겸양어로 '이야기하고 싶습니다'라는 뜻입니다. 강연이나 발표에서 주제를 제시할 때 자주 사용합니다.
〜と思います
자신의 의견이나 추측을 부드럽게 표현하는 패턴. 단정적으로 말하지 않고 의견을 피력할 때 씁니다. 발표·회화에서 매우 빈번하게 나옵니다.
〜であるがゆえに
「〜であるがゆえに」는 원인·이유를 강조하는 문어체 표현입니다. 구어에서는 「〜だから」나 「〜なので」가 더 일반적이지만, 논리적이거나 공식적인 문맥에서 사용합니다.
〜というのは〜
「〜というのは」는 어떤 대상을 화제로 올려 그것에 대해 설명할 때 씁니다. 「匿名コミュニティというのはギブアンドテイクの精神が非常に強い」처럼 정의를 내릴 때 많이 사용합니다.
〜とも言うべき
「〜べき」는 '~해야 한다'는 당위·필연을 나타냅니다. 「〜とも言うべき」는 '~라고도 말할 수 있는'이라는 뉘앙스로 격식 있는 표현입니다.
〜てしまう
「〜てしまう」는 동작의 완료를 나타내거나, 바람직하지 않은 일이 일어났음을 나타냅니다. 여기서는 '멋대로 상표 등록을 해 버리다', '인터넷이 불타오르게 되어 버리다'처럼 부정적 결과를 표현할 때 사용되었습니다.
〜たり〜たりする
「〜たり〜たりする」는 여러 가지 동작이나 상태를 병렬로 나열할 때 씁니다. 모든 것을 열거하지 않아도 됩니다. 이 강연에서는 「コラージュされたり」「おもちゃにされたりして」처럼 사용되었습니다.
〜ていただく
「〜ていただく」는 「もらう」의 겸양어로 상대방이 자신을 위해 어떤 행동을 해줄 때 씁니다. 청중을 향한 경어 표현으로 강연에서 자주 등장합니다. (예: 「見ていただいたら」「検索していただいても」)
〜させていただく
「〜させていただく」는 자신의 행동을 허가·혜택으로 간주하여 겸손하게 말하는 표현입니다. 「お話をさせていただきたい」「共有させていただきたい」처럼 발표나 공식 석상에서 자주 쓰입니다.
〜ている / 〜ておられる
「〜ておられる」는 「〜ている」의 경어형으로 상대방 혹은 제3자의 상태를 존경하여 표현합니다. 「欲しておられる」는 '원하고 계신다'는 존경 표현입니다.
〜ということであれば
「〜ということであれば」는 '만약 ~라는 것이라면'이라는 조건을 나타냅니다. 상대방의 상황을 전제로 조언이나 권유를 할 때 씁니다.
〜なり〜なり
「〜なり〜なり」는 여러 가지 방법 중 하나를 선택하도록 예시를 들 때 씁니다. 「メールなり」「Googleで検索してなり」처럼 선택지를 제시합니다.
〜考えております
「〜考えております」는 「〜考えています」의 겸양어입니다. 「おります」는 「います」의 겸양형으로 자신의 상태나 동작에 대해 겸손하게 표현할 때 씁니다.
〜というふうに考えたりします
「〜というふうに」는 '~이런 식으로, ~라고'의 뜻. 「〜たりします」는 여러 행동 중 하나임을 나타내며 전체적으로 단정을 피하고 부드럽게 의견을 표현합니다.
〜んです / 〜のです
「〜んです」「〜のです」는 청자가 이미 알고 있거나 눈앞의 상황에 대해 설명·해석할 때 씁니다. 「商品化できるんです」는 '상품화할 수 있는 겁니다'처럼 이유를 제공하거나 강조할 때 사용됩니다.
