04   Grammar Patterns

Key grammar structures used in the video. Each pattern includes real examples.

〜をお見せします (Humble Verb: お〜します)
The honorific humble form お + verb stem + します is used when the speaker does something for the listener, showing respect. Here お見せします = 'I will show you (humbly)'.
お + 동사 어간 + します 형태는 화자가 청자를 위해 행동할 때 사용하는 겸양 표현입니다. お見せします = '(제가) 보여 드리겠습니다'.
今日は私たちの伝統的な日本の家をお見せします。
ご案内します。
お手伝いします。
〜ことができます (Potential: can do)
verb dictionary form + ことができます expresses the potential/ability to do something. More formal than the plain potential form (〜られる).
동사 기본형 + ことができます는 어떤 것을 할 수 있는 능력이나 가능성을 나타냅니다. 평어 가능형(〜られる)보다 격식체입니다.
この部屋はふすまで仕切ることができます。
体を洗うことができます。
水で洗うことができます。
〜に関して (Regarding / About)
〜に関して is a formal expression meaning 'regarding', 'about', or 'concerning'. It is used to introduce or elaborate on a topic.
〜に関して는 '~에 관해서', '~에 대해서'를 의미하는 격식체 표현으로, 화제를 도입하거나 설명할 때 씁니다.
この部屋はふすまで仕切ることができます。
日本の文化についてお聞かせください。
〜と呼ばれています (Is called / Is known as)
〜と呼ばれています is a passive expression meaning 'is called' or 'is known as'. と = quotation marker, 呼ばれる = passive of 呼ぶ (to call), います = ongoing state.
〜と呼ばれています는 '~라고 불립니다', '~라고 알려져 있습니다'를 의미하는 수동태 표현입니다. と = 인용 조사, 呼ばれる = 呼ぶ의 수동형, います = 지속적 상태.
松竹梅と呼ばれています。
東京と呼ばれています。
侍と呼ばれていました。
〜てください (Polite Request: Please do〜)
〜てください is a standard polite request form. te-form of verb + ください. More formal than just saying the te-form alone.
〜てください는 표준적인 정중한 의뢰 표현입니다. 동사의 て형 + ください. て형만 단독으로 쓰는 것보다 격식 있습니다.
皆さんに質問があります。お聞かせください。
日本の文化についてお聞かせください。
日本のオタク文化を聞いてみてください。
〜と言うことができます (One can say that〜)
〜と言うことができます literally means 'one can say that〜'. It is used to introduce a description or name for something. More formal than just 〜です.
〜と言うことができます는 '~라고 말할 수 있습니다'를 의미합니다. 무언가에 대한 설명이나 명칭을 소개할 때 씁니다. 단순 ~です보다 격식체입니다.
障子と言うことができます。
これを伝統的な建築と言うことができます。
〜てみてください (Please try doing〜)
〜てみてください = te-form of verb + みて (try doing) + ください (please). Suggests the listener should try or attempt something.
〜てみてください = 동사 て형 + みて (해보다) + ください (부탁). 청자에게 무언가를 시도해 보도록 권유하는 표현입니다.
日本のオタク文化を聞いてみてください。
これを食べてみてください。
日本語を話してみてください。
〜に住んでいます (Ongoing State: living in〜)
〜に住んでいます expresses a continuous state of living somewhere. に = location marker, 住む (すむ) = to live/reside, でいます = te-form of いる indicating ongoing state.
〜に住んでいます는 어느 곳에 살고 있는 지속적인 상태를 나타냅니다. に = 장소 조사, 住む = 살다, でいます = 진행·상태의 て형 + いる.
今、秋葉原の東京に住んでいます。
日本の新しい家族として住んでいることについてお聞かせください。
大阪に住んでいます。
〜を使うことで (By using〜)
〜を使うことで means 'by using〜' or 'through the use of〜'. で here is the te-form equivalent of a noun clause meaning 'by means of'.
〜を使うことで는 '~를 사용함으로써'를 의미합니다. で는 수단을 나타내는 조사로, 명사절 뒤에 붙어 '~를 통해'라는 의미를 줍니다.
これを使うことで、部屋が明るくなります。
障子を使うことで、自然光が入ります。
〜に興味があります (To be interested in〜)
〜に興味があります is a standard expression for saying one is interested in something. に marks the object of interest, 興味 = interest, があります = exists/have.
〜に興味があります는 무언가에 관심이 있다고 표현하는 기본적인 표현입니다. に = 관심의 대상을 나타내는 조사, 興味 = 흥미, があります = 있습니다.
私は、日本の人に興味があります。
日本語に興味があります。
伝統文化に興味があります。

05   Keigo & Speech Styles

Politeness levels and speech styles used in this video. Understanding these is essential for natural Japanese!

Keigo Sonkeigo
お聞かせください → おきかせください
お聞かせください는 尊敬語(존경어) 의뢰 형태입니다: お + 聞かせ(聞く의 사역형 어간) + ください. 청자에게 무언가를 들려달라고 정중히 요청하는 표현.
Keigo Kenjougo
お見せします → おみせします
お見せします는 謙譲語(겸양어) 형태입니다: お + 見せ(見せる의 어간) + します. 화자가 자신의 행동(보여주기)을 낮추어 청자를 높이는 표현.
Keigo Teineigo
ございます → ございます
ございます는 あります(있습니다)의 가장 격식 높은 정중한 형태입니다. 매우 공식적이거나 정중한 상황에서 사용. おはようございます = 정중한 '안녕하세요(아침 인사)'.
Pitch Accent
玄関 → げんかん
玄関(げんかん)은 평판형 악센트: げ(낮음)→ん(높음)→か(높음)→ん(높음). 첫 모라 げ가 낮고 이후 높아집니다. 도쿄 방언에서 복합 명사에 흔한 악센트 패턴.
仏壇 → ぶつだん
仏壇(ぶつだん)은 頭高型(두고형) 악센트: ぶ(높음)→つ(낮음)→だ(낮음)→ん(낮음). 첫 모라 ぶ에서 높았다가 이후 낮아집니다.
Contraction Colloquial
わかりました → わかりました
わかりました는 わかる(이해하다)의 격식 과거형입니다. 빠른 구어체에서는 わかった(반말)로 줄어들기도 하고, 매우 빠른 발화에서는 わかりまし로 끊어지기도 합니다.
Sound Change N Before Bilabial
伝統 → でんとう
でんとう에서 ん은 치경 비음 [n]이지만, でんぱ(전파)처럼 ん이 p/b 앞에 오면 양순 비음 [m]으로 변합니다. ん의 이음 변이는 자연스러운 일본어 발음에 중요합니다.
Keigo Form Comparison
あります / ございます → あります / ございます
둘 다 '있다/있습니다'를 뜻하지만 경어 수준이 다릅니다: ある(반말) → あります(정중체) → ございます(매우 격식). 영상에서 두 형태 모두 사용됨.
Sound Reduction Fast Speech
おはようございます → おはようございます
빠른 일상 발화에서 おはようございます는 おはよう(반말)나 おはよっす(매우 구어적)로 줄어듭니다. 영상에서는 정중한 상황에서 전체 형태를 사용.
Particle Topic Marker
〜は (topic marker) → は
조사 は는 문자는 'ha(は)'이지만 주제 조사로 쓰일 때는 'wa(わ)'로 발음됩니다. 예: 玄関は → げんかんわ. 초학자들이 자주 틀리는 발음 규칙.
Keigo Teineigo Ending
〜ます / 〜ません → 〜ます / 〜ません
ます 어미는 정중한 동사 활용형입니다. 영상의 모든 동사는 ます(긍정) 또는 ません(부정)으로 끝납니다. 공적·준공식 상황에서 기대되는 기본 丁寧語(정중체) 수준.
