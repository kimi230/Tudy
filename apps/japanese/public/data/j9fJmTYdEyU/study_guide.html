6 任天堂スイッチ2との競争 0:01 ~ 0:06
스위치2는 5만 엔으로 부모 입장에서 더 접근하기 쉬운 가격. 4개월 만에 1,000만 대 판매(닌텐도 역대 최고 페이스). 가전양판점은 입고 대기·품절 상태. 어린이들 사이에서도 스위치2 압도적 인기. 이유는 휴대 가능성, 게임 편의성, 가격 모두에서 스위치2 우세. 소니는 기민하게 가격 인하로 반격 시도.

새 모델은 일본어만 지원, 일본 사이트에서만 구매 가능, 일본 계정 필요. 이유는 전매 방지: 엔화 약세로 해외 방문객이 일본에서 싸게 구매 후 타국에 전매하는 문제 발생. 메루카리·중국 쇼핑앱에서 PS5 일본판(日版)이 대량 유통 중. 전매 상품이 해외에서 유통되면 소니가 실질 손해를 입는 구조.

04   Grammar Patterns

Key grammar structures used in the video. Each pattern includes real examples.

〜によって / 〜による
동작의 주체나 원인·수단을 나타냄. 명사에 접속. による는 명사를 수식할 때 사용.
〜ていただきます
동사의 て형 + いただく. 상대방이 해준 것을 받는다는 뜻의 경어. お送りします도 경어 표현.
〜というわけ
이유나 결론을 명확하게 설명할 때 사용. 「というわけだ / というわけです / というわけですね」형태로 자주 쓰임.
〜に合わせる
기준·기준점에 맞게 조정한다는 의미. 「〜に合わせてくる」는 '~에 맞춰오다(전략적 행동)'.
なかなか〜ない
기대와 달리 어떤 상태가 쉽게 실현되지 않을 때 사용. なかなか는 부정문과 함께 써야 이 의미가 됨.
〜からすると / 〜からすれば
어떤 관점·입장을 기준으로 판단할 때 사용. 「〜の立場から見ると」와 유사.
〜しか〜ない
「しか」는 부정을 동반해 한정을 나타냄. 「だけ」와 비교: しか는 제한의 뉘앙스가 강함.
〜ない限りは
어떤 조건이 충족되지 않으면 후술 내용이 실현되지 않음을 나타냄. 「〜なければ〜ない」보다 강한 조건.
〜てもらう / 〜てもらいたい
상대방이 나를 위해 어떤 행동을 해주는 것을 나타냄. 「楽しんでもらう」= 즐겨 주기를 바라다.
〜かもしれない
불확실한 추측을 나타내는 문말 표현. 「〜だろう」보다 불확실성이 높음.
〜ていくと
어떤 과정이나 분석이 진행되어 가는 방향성을 나타냄. 변화의 진행을 설명할 때 사용.
いずれにしろ
여러 경우 중 어느 것이든 결론은 같다는 의미. 「とにかく」「どちらにせよ」와 유사.
〜にしろ (〜にせよ)
いずれにしろ의 〜にしろ는 양보의 의미. 「〜であっても」와 유사.
というふうに
어떤 방식이나 내용을 부드럽게 인용·설명할 때 사용하는 구어적 표현.
〜てしまう
의도치 않게 혹은 완전히 끝나버리는 동작을 나타냄. 후회·유감의 뉘앙스를 포함하기도 함.
