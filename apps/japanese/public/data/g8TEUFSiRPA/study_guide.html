04   Grammar Patterns

Key grammar structures used in the video. Each pattern includes real examples.

〜かもしれない
어떤 사실에 대해 확신은 없지만 가능성이 있음을 나타내는 표현. 동사·형용사의 보통형에 접속함.
〜ていきたい
동사 て형 + いきたい. 현재 상태에서 앞으로 계속 어떤 행동을 해나가겠다는 화자의 의지나 바람을 표현함.
〜ように
동사 사전형/ない형 + ように. 어떤 결과나 상태가 되도록 행동한다는 목적을 표현함. '~이 되도록', '~할 수 있도록'의 의미.
〜つつ
동사 ます형 + つつ. 두 행위를 동시에 하는 것을 나타냄. 문어체적 표현으로 ながら보다 격식체임.
〜ながら
동사 ます형 + ながら. 두 가지 행동이 동시에 일어남을 나타냄. 일상적으로 널리 쓰이는 표현.
〜っていうのは / 〜っていう
「という」의 구어 축약형. 일상 대화에서 자주 쓰임. 어떤 사실이나 개념을 설명하거나 인용할 때 사용.
〜なければならない
동사 ない형 + ければならない. 어떤 행동을 반드시 해야 한다는 강한 의무를 표현함.
〜とともに
명사 + とともに. 어떤 것이 변화할 때 다른 것도 함께 변화함을 나타냄. '~함에 따라', '~과 동시에'의 의미.
〜からこそ
명사·동사 보통형 + からこそ. 특정 이유가 바로 그 결과의 핵심 원인임을 강조하는 표현. '~이기 때문에 특히'의 뉘앙스.
〜を経て
명사 + を経て. 어떤 경험이나 단계를 통과한 후에 다음 단계로 나아감을 나타냄.
〜ならば / 〜なら
명사·형용사·동사 보통형 + なら(ば). 어떤 조건이나 가정을 설정하고 그에 따른 결과를 말하는 표현.
〜ならでは
명사 + ならでは. 그것에만 특유한 특징이나 장점을 강조하는 표현. '~만이 할 수 있는', '~특유의' 의미.
〜ていただける
동사 て형 + いただける. 「もらう」의 겸양어 「いただく」의 가능형. 상대방이 자신을 위해 무언가를 해줄 수 있음을 공손히 표현함.
〜のが大事だ
동사 사전형 + のが大事だ. 어떤 행위가 중요함을 나타내는 표현. の는 명사화 조사.

05   Keigo & Speech Styles

Politeness levels and speech styles used in this video. Understanding these is essential for natural Japanese!

Keigo
不可欠です → ふかけつです
丁寧語
「不可欠だ」(불가결하다)에 정중한 어미 「です」를 붙인 형태. 사실을 정중하게 단정하는 표현.
나레이션이나 공식 발화에서 사실을 정중하게 설명할 때 사용
あります → あります
丁寧語
「ある」(있다)의 정중한 형태. 사물이나 상태의 존재를 정중하게 표현함. 사람에게는 「います」를 사용함에 주의.
인터뷰에서 자신의 상황을 정중하게 설명할 때
していただけると思うんですよ → していただけるとおもうんですよ
謙譲語
「もらう」의 겸양어 「いただく」의 가능형 「いただける」를 사용한 표현. '상대방이 해줄 수 있다'는 것을 겸손하게 표현함. 〜んですよ는 설명이나 강조의 뉘앙스.
상대방에게 은혜를 입음을 겸손하게 표현할 때
なりません → なりません
丁寧語
「ならない」(안 된다)의 정중한 부정형. 「しなければならない」는 '해야 한다'는 의무를 나타내며, その丁寧形가 「しなければなりません」.
규칙이나 의무를 정중하게 설명할 때
立ち上げました → たちあげました
丁寧語
동사 「立ち上げる」(설립하다)의 과거형에 정중어미 「ました」를 붙인 형태. 과거의 완료된 행동을 정중하게 전달함.
과거에 완료된 사실이나 행동을 정중하게 보고할 때
取りました → とりました
丁寧語
동사 「取る」(취하다)의 과거 정중형. 「〜という形を取りました」는 '〜라는 형태를 취하게 됐습니다'라는 뜻의 공손한 표현.
자신들의 결정이나 방법을 정중하게 설명할 때
いるといいます → いるといいます
丁寧語
「〜といいます」는 '〜라고 합니다'라는 전문(傳聞) 표현의 정중형. 타인으로부터 들은 정보를 전달할 때 사용함.
나레이션에서 제3자에게 들은 정보를 정중하게 전달할 때
購入していただけるような → こうにゅうしていただけるような
謙譲語
「買ってもらえる」(사줄 수 있는)을 겸양어로 표현한 형태. 「いただく」는 「もらう」의 겸양어로 상대방의 행동에 감사를 나타냄.
고객이 자신들의 상품을 구입해 줄 것을 겸손하게 바랄 때
目指しています → めざしています
丁寧語
「目指している」(목표로 하고 있다)의 정중형. 현재 진행 중인 상태나 목표를 정중하게 표현함.
자신들의 목표나 활동을 정중하게 말할 때
受け持ちます → うけもちます
丁寧語
「受け持つ」(담당하다)의 정중형. 나레이션이나 설명에서 정중하게 사실을 전달할 때 사용.
분업 시스템을 나레이션에서 정중하게 설명할 때
応援してきました → おうえんしてきました
丁寧語
「応援してきた」(응원해 왔다)의 정중형. 과거부터 현재까지의 계속된 행동을 정중하게 표현함.
스승이 제자들에 대한 지속적인 지원을 정중하게 전달할 때
守ってきました → まもってきました
丁寧語
「守ってきた」(지켜왔다)의 정중형. 과거부터 현재까지 계속되어 온 행동이나 상태를 정중하게 나타냄.
나레이션에서 전통이 오랜 시간 유지되어 왔음을 정중하게 설명할 때
込められています → こめられています
丁寧語
수동형 「込められる」(담겨있다)의 현재 정중형. 어떤 의미나 감정이 담겨 있다는 것을 정중하게 표현함.
나레이션에서 회사 이름에 담긴 의미를 정중하게 설명할 때
Teineigo / 丁寧語 (정중어)
ですね → ですね
丁寧語
「だ」의 정중형 「です」에 확인·공감을 구하는 종조사 「ね」가 붙은 형태. 상대방의 동의를 구하거나 감정을 부드럽게 전달할 때 사용. 이 영상에서 여러 번 등장하는 전형적인 구어 표현.
화자가 자신의 감정이나 판단을 상대방과 공유하고자 할 때
ですかね → ですかね
丁寧語
「です」에 의문의 「か」와 여운을 주는 「ね」가 결합한 형태. 자신의 생각을 단정짓지 않고 부드럽게, 다소 자문(自問)하는 듯한 뉘앙스로 표현함. 인터뷰에서 자주 등장하는 전형적인 말끝 표현.
