# stdyEng UI/UX Design Brief

> YouTube 영상 기반 10단계 영어 학습 플랫폼

**작성일:** 2026-02-16
**대상:** Frontend 개발자, UI/UX 디자이너
**현재 스택:** React 19 + TypeScript + Tailwind CSS + Vite

---

## 1. 프로젝트 개요

### 1.1 핵심 컨셉

YouTube 영어 영상을 자동 분석하여 **10단계 체계적 학습 콘텐츠**로 변환하는 플랫폼.
사용자는 영상을 선택하고, 듣기 → 분석 → 출력의 3단계 학습 사이클을 통해 영어를 학습한다.

### 1.2 핵심 가치

| 가치 | 설명 |
|------|------|
| **체계적 학습** | 단순 시청이 아닌 10단계 구조화된 학습 프로세스 |
| **AI 분석** | 어휘, 문법, 연음, 구조를 자동 분석하여 학습 보조 자료 제공 |
| **자기주도** | 노트 작성, 이해도 체크, 녹음 비교 등 능동적 학습 유도 |
| **진도 추적** | 학습 세션, 오답 노트, 녹음 기록을 로컬에 영구 보존 |

### 1.3 대상 사용자

- **한국어 모국어 사용자** (UI 전체 한국어)
- 영어 학습에 관심 있는 성인 (초급~고급)
- TED, 비즈니스, 일상회화 등 다양한 주제의 영어 콘텐츠로 학습하고자 하는 사용자

## 2. 정보 구조 (Information Architecture)

### 2.1 사이트맵

```
홈 (/)
├── 카테고리 (/category/:categoryId)
│   └── 학습 (/study/:videoId)  ← 핵심 페이지
│       └── 10단계 학습 워크플로우 (Step 1~10)
│
├── 나의 학습 (/library)
│   └── 학습 이어하기 → /study/:videoId
│
├── 오답노트 (/error-notes)
│
├── 어휘장 (/vocabulary)
│
└── URL 요청 (/request)
```

### 2.2 네비게이션 구조

**Header (Global Navigation)**
- 로고/앱 이름: "stdyEng"
- 메뉴: 홈 | 나의 학습 | 오답노트 | 어휘장 | URL 요청
- 모바일: 햄버거 메뉴 → 슬라이드 드로어

**Sidebar (홈 페이지 전용, lg 이상)**
- 카테고리 목록 (10개 카테고리, 아이콘 포함)
- 현재 카테고리 하이라이트

#### 표시 데이터

|------|------------|----------|

| URL 요청 | localStorage | URL 입력 필드 |

- 카테고리 클릭 → `/category/:categoryId`
- 영상 카드 클릭 → `/study/:videoId`
- URL 요청 제출 → localStorage 저장 + 성공 메시지

```
│ ┌──────────────┐ ┌──────────────┐      │
│ │ [Thumbnail]  │ │ [Thumbnail]  │      │
│ │ Title        │ │ Title        │      │
│ │ Channel      │ │ Channel      │      │
│ │ 🟢초급 6:13  │ │ 🟡중급 12:45 │      │
```

#### 표시 데이터

| 항목 | 데이터 | 설명 |
|------|--------|------|
| 카테고리 메타 | `categories.json` | id, name, icon, description |
| 영상 목록 | `videos.json` (categoryId 필터) | 썸네일, 제목, 채널, 난이도, 재생시간, WPM |

#### 영상 카드 컴포넌트 상세

```
┌─────────────────────────┐
│ [YouTube 썸네일 이미지]    │
│                          │
├─────────────────────────┤
│ Grit: The Power of...   │  ← 제목 (2줄 말줄임)
│ TED                      │  ← 채널명
│ 🟡 중급  ·  6:13         │  ← 난이도 배지 + 재생시간
│ 143 WPM                  │  ← 발화 속도
└─────────────────────────┘
```

**난이도 배지 색상:**
- 🟢 초급 (beginner) → green
- 🟡 중급 (intermediate) → yellow/amber
- 🔴 고급 (advanced) → red

#### 목적

```
│ │                                                          │ │

│ │  ① ② ③           ④ ⑤ ⑥           ⑦ ⑧ ⑨ ⑩              │ │
│ │  ○ ○ ○           ○ ○ ○           ○ ○ ○ ○              │ │
│ │                                                          │ │
│ │ 색상: ⚪ 대기 | 🔵 진행중 | 🟢 완료                       │ │
│ └─────────────────────────────────────────────────────────┘ │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│ [현재 Step 콘텐츠 영역]                                       │
```

#### Step Indicator 3구간 분류

| 구간 | 단계 | 이름 | 목표 |
|------|------|------|------|
| **듣기 (Listening)** | 1, 2, 3 | 전체 듣기, 노트 정리, 구간 체크 | 자기 힘으로 영상 이해 시도 |
| **분석 (Analysis)** | 4, 5, 6 | 비교, 세부 분석, 복습 | AI 분석 자료와 비교/학습 |
| **출력 (Output)** | 7, 8, 9, 10 | 오답노트, 쉐도잉, 녹음, 요약 | 배운 내용 체화/출력 |

**목표:** 자막 없이 영상을 처음부터 끝까지 시청

```
┌─────────────────────────────────────────────────┐
│ Step 1. 전체 듣기                                 │
│ "자막 없이 영상을 끝까지 시청하세요."                │
├─────────────────────────────────────────────────┤
│ ┌─────────────────────────────────────────┐      │
│ │                                          │      │
│ │         [YouTube Player]                 │      │
│ │          (자막 OFF)                       │      │
│ │                                          │      │
│ └─────────────────────────────────────────┘      │
│                                                   │
│ 재생 속도: [0.5x] [0.75x] [1x] [1.25x] [1.5x]   │
│ 현재 시간: 02:34 / 06:13                          │

```

**데이터:** `meta.json` (영상 메타), YouTube IFrame API

#### Step 2: 노트 정리 (Cornell Notes)

**목표:** 들은 내용을 코넬 노트 방식으로 정리

```
┌─────────────────────────────────────────────────┐
│ Step 2. 노트 정리                                 │
│ "들은 내용을 코넬 노트로 정리하세요."                │
├─────────────────────────────────────────────────┤
│ ┌─────────────────────────────────────────────┐  │
│ │ 시그널 표현 가이드 (접기/펼치기)                │  │
│ │ · "First of all" → 첫 번째 요점 시작           │  │
│ │ · "In other words" → 핵심 내용 재설명          │  │
│ │ · "To sum up" → 결론/요약 시작                 │  │
│ └─────────────────────────────────────────────┘  │
│                                                   │
│ ┌──────────┬────────────────────────────────┐    │
│ │ Cues     │ Notes                           │    │
│ │ (핵심어)  │ (들은 내용)                      │    │
│ │          │                                  │    │
│ │ [텍스트   │ [텍스트 입력 영역]                │    │
│ │  입력]    │                                  │    │
│ │          │                                  │    │
│ ├──────────┴────────────────────────────────┤    │
│ │ Summary (요약)                              │    │
│ │ [텍스트 입력 영역]                            │    │
│ └─────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────┘
```

**데이터:** `structure.json` → `signalExpressions[]` (시그널 표현 가이드)
**저장:** IndexedDB `sessions` → `cornellNotes: { cues, notes, summary }`

```
│                           │ ├──────────────────────────────┤ │
│                           │ │ 00:14 I left a very demanding│ │
│                           │ │        [🔵이해] [🔴어려움]    │ │
│                           │ ├──────────────────────────────┤ │

```

**데이터:** `segments.json` → 각 세그먼트의 `textEn`, `start`, `end`

**저장:** IndexedDB → `markedSegments: [{ segmentIndex, color: 'blue'|'red' }]`
**인터랙션:**
- 세그먼트 클릭 → YouTube 해당 시간으로 점프
- 현재 재생 중인 세그먼트 자동 하이라이트 (스크롤 추적)
- 파랑/빨강 버튼으로 마킹 토글

**목표:** 자신의 노트 vs AI 분석 스피치 구조 비교

```
│                           │                                   │
│ Cues:                     │ ■ 도입 (Intro)                    │

│                           │   "교사 경험을 통해 IQ가..."       │
│ Notes:                    │   시그널: "When I was 27..."      │
│ [사용자 작성 내용]          │                                   │
│                           │ ■ 본론 (Body)                     │
│ Summary:                  │   Seg 10~70                       │
│ [사용자 작성 내용]          │   핵심: "Grit이란 장기 목표를..."  │

```

**데이터:**
- 좌측: IndexedDB → `cornellNotes`
- 우측: `structure.json` → `sections[]` (type, summary, summaryKo, keyPoints, signalExpressions)

**데이터 매핑 (세그먼트 인덱스 기반 연결):**

| 탭 | 데이터 소스 | 필터 조건 | 표시 필드 |
|----|-----------|----------|----------|

## 4. 데이터 스키마 종합

### 4.1 정적 데이터 (서버/빌드타임 생성)

```
frontend/public/data/
├── categories.json         ← 10개 카테고리 정의
├── videos.json             ← 전체 영상 인덱스
└── {videoId}/
    ├── meta.json           ← 영상 메타데이터 + 통계
    ├── segments.json       ← 자막 (EN+KO + 단어별 타임스탬프)
    ├── vocabulary.json     ← 핵심 어휘 15~30개
    ├── grammar.json        ← 문법 패턴 8~15개
    ├── connected_speech.json ← 연음 현상 10~20개
    └── structure.json      ← 스피치 구조 + 시그널 표현
```

### 4.2 클라이언트 데이터 (IndexedDB)

| Store | 용도 | Key | 인덱스 |
|-------|------|-----|--------|
| `sessions` | 학습 세션 진행 상태 | id (string) | videoId |
| `errorNotes` | 오답 노트 | autoIncrement | videoId, errorType |
| `recordings` | 녹음 파일 (Blob) | autoIncrement | sessionId |
| `requests` | URL 요청 이력 | autoIncrement | - |

### 4.3 핵심 데이터 흐름

```
[YouTube URL]
    ↓
[Phase 1: 다운로드+STT]
    ↓
[_clean_segments.json] ← 영어 자막만
    ↓
[Phase 2: Claude Code 분석]
    ↓
[6개 JSON 파일] ← segments, vocabulary, grammar, connected_speech, structure, meta
    ↓
[videos.json 인덱스 업데이트]
    ↓
[Frontend: 정적 JSON 로딩]
    ↓
[사용자 학습 → IndexedDB에 진행상황 저장]
```

```
홈 방문

        → Step 2: 코넬 노트 작성
        → Step 3: 이해/미이해 구간 마킹
        → Step 4: 내 노트 vs AI 구조 비교
        → Step 5: 세그먼트별 듣기→추측→확인, 어휘/문법/연음
        → Step 6: 전체 재시청 + 이해도 평가
        → Step 7: 오답 노트 작성
        → Step 8: 3단계 쉐도잉
        → Step 9: 녹음 후 원본 비교
        → Step 10: 요약 작성 + 학습 완료
```

## 10. 핵심 인터랙션 패턴

### 10.1 YouTube 플레이어 동기화

- 세그먼트 클릭 → 해당 타임스탬프로 점프
- 재생 중 → 현재 세그먼트 자동 하이라이트 (200ms 간격 추적)
- 재생 속도 조절: 0.5x, 0.75x, 1x, 1.25x, 1.5x, 2x
- 구간 반복 재생 (start ~ end 타임스탬프 활용)

### 10.2 자동 저장

- 학습 세션 30초마다 IndexedDB 자동 저장
- 단계 완료 즉시 저장
- 노트 변경 시 자동 저장
- 마킹 변경 시 즉시 저장

### 10.3 답 확인 패턴 (Step 5)

```
[초기 상태] 영어 텍스트만 표시
     ↓
[답 확인하기] 버튼 클릭
     ↓
[한국어 번역 표시] + [이해됨/복습필요] 버튼 표시
     ↓
[선택] → 다음 세그먼트로 이동
```

### 10.4 녹음 플로우 (Step 9)

```
[녹음 시작] → 브라우저 마이크 권한 요청
     ↓
[녹음 중] → 실시간 녹음 (MediaRecorder API)
     ↓
[녹음 중지] → Blob → IndexedDB 저장
     ↓
[재생] → 원본과 번갈아 비교 청취
```

## 11. 기술 제약 사항

| 항목 | 현재 상태 | 비고 |
|------|----------|------|
| 서버 | 없음 (정적 파일 서빙) | 모든 데이터는 public/data/ 정적 JSON |
| DB | IndexedDB (브라우저 로컬) | 기기간 동기화 없음 |
| 인증 | 없음 | 로그인 불필요 |

| 오프라인 | JSON 한번 로드 후 캐시 가능 | 녹음은 로컬 저장 |
